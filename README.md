# Susu & Neko's Dictation Adventure

An interactive English dictation revision website for Primary 2 (Hong Kong), covering PLE 2A Unit 2 vocabulary, key words, key structures and the "How to behave in public places" reading sentences.

- 13 levels: learn, listen & pick, letter jumble, missing letters, spelling, sentence builder, sentence writing and a final dictation test
- Recorded native English female voice for every word, letter and sentence
- Characters: Susu and Neko

It is a static site: open `index.html` in a browser, or host it with GitHub Pages.
